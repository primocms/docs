## Manage library blocks

Open **Library** from the server dashboard. Choose a group to browse its blocks, open a block to edit its code and default content, or create a block to add a reusable template.

<Steps>
  <Step title="Create a group">
    Use the group controls to create a named group, such as Navigation or Content. Select it before creating or importing blocks.
  </Step>
  <Step title="Create or import a block">
    Choose **Create Block** to write a Svelte block with fields, or **Import** to select a compatible `.json` block export. Save the block and check its preview.
  </Step>
  <Step title="Organize and export">
    Use a block's menu to rename it, move it to another group, download its `.json` export, or delete it.
  </Step>
  <Step title="Use it in a site">
    Open a site's page type editor and add a library block in the Blocks tab. Place it in the shared template or enable it for editors to add to page bodies.
  </Step>
</Steps>

<Note>
Primo copies a library block into the site. Existing site copies do not receive later changes to the library original. See [Using the component library](/building-sites/using-the-component-library) for update and reuse workflows.
</Note>

<Warning>
Deleting a library group deletes the library blocks inside it. Move blocks you want to keep before deleting the group.
</Warning>

## Back up the library

Download individual blocks as `.json` files, or use [`primo library pull`](/cli/sync#library-only-sync) to export the full library into a CLI workspace. Keep a PocketBase backup for the server's complete state.
