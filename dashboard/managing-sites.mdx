## Create sites from the dashboard

<Steps>
  <Step title="Open Sites">
    Sign in and open the Sites dashboard at `/admin/dashboard/sites`. Select the group where you want the site, then choose **Create Site**.
  </Step>
  <Step title="Choose a starting point">
    Enter a name, choose an existing site, a marketplace starter, or a blank starter, then review optional blocks and create the site.
  </Step>
  <Step title="Open the editor">
    Open the new site from its card. You can edit it through `/admin/sites/<site-id>` before it has a public hostname.
  </Step>
  <Step title="Connect a domain">
    Use the site's menu → **Assign domain**. Follow the displayed DNS instructions. With manual domain setup, configure your reverse proxy and TLS, then use **Mark as connected** after verifying reachability. See [Deployment](/reference/deployment) for Railway and VPS setup.
  </Step>
</Steps>

<Note>
One public hostname routes to one site. You can create multiple sites on a server before connecting domains. If the server has `PRIMO_BASE_DOMAIN` configured, new sites receive subdomains; wildcard DNS and TLS must also be configured.
</Note>

## Site Groups

**Site Groups** help you organize multiple sites into folders. They organize the dashboard; they do not create publishing stages, separate environments, or different permissions.

### Example group names

You choose the group names. For example:

- **Client Organization**: Group sites by client (e.g., "Client A Sites", "Client B Sites")
- **Project Type**: Organize by type (e.g., "Blogs", "Portfolios", "E-commerce")
- **Work Status**: Separate sites by stage (e.g., "In Development", "Live Sites", "Personal Projects")

### Managing Site Groups

<Steps>
  <Step title="Create a group">
    Use the sidebar group controls to choose **Create Group** and enter a name. A group created during setup can also be renamed.
  </Step>

  <Step title="Move sites between groups">
    Click the three-dot menu on any site → "Move" → Select the destination group.
  </Step>

  <Step title="Rename a group">
    Click the dropdown next to the group name → "Rename".
  </Step>

  <Step title="Delete a group">
    Click the dropdown next to the group name → "Delete".
  </Step>
</Steps>

<Warning>
Deleting a site group deletes all sites within it. Move sites out of a group before deleting it if you want to keep them.
</Warning>

## Managing Individual Sites

Each site card in the dashboard provides quick actions:

**Rename**: Change the site's display name (doesn't affect the domain)

**Move**: Move the site to a different group

**Download**: Export the site as a `.primo` snapshot. Use the CLI pull workflow for YAML and Svelte files; neither export includes server accounts and settings.

**Delete**: Permanently delete the site and all its content

<Warning>
Deleting a site is permanent and cannot be undone. All pages, blocks, and content will be lost.
</Warning>
