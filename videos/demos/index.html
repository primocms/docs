Start Primo locally

Garden Demo · 34.95s · Download MP4
Read the steps
  1. With Node.js and the CLI installed, create a workspace. This demo skips MCP setup.
  2. Inside the workspace, create a site. --skip-dev leaves starting the server to you.
  3. Validate the site files before starting Primo.
  4. Run primo dev --author files. Open its editor URL: Browse mode keeps local files authoritative.
  5. Stop with Ctrl+C, then run primo dev --author cms to edit in the browser.

Recover from a refused CLI push

Garden Studio · 44.0s · Download MP4
Read the steps
  1. Pull from the server to record a baseline. Here PRIMO_SERVER points to an isolated local demo.
  2. After a local code edit and a server edit, push refuses to overwrite the newer server version.
  3. Save the edited file outside sites/, then pull the latest server copy.
  4. Reapply the saved code edit and push again. The server change is preserved.
  5. The pushed headline appears in the CMS. On a hosted server, review and Publish to update the public site.

Connect a Railway hostname and publish a site

Garden Studio · 80.95s · Download MP4
Read the steps
  1. Use the Railway-generated hostname. Its DNS routing and HTTPS are already configured by Railway.
  2. The prepared site begins without a public hostname assigned in Primo.
  3. Open the site menu and choose Assign domain.
  4. Enter the Railway hostname without https:// or a path, then choose Connect.
  5. For this generated Railway hostname, skip registrar DNS steps: routing and HTTPS are already verified.
  6. Mark as connected records manual connection status. It does not publish the site.
  7. Open the editor and choose Publish. Confirm the destination, then choose Publish changes.
  8. Wait for Changes published before viewing the public site.
  9. Open the public HTTPS homepage and verify the saved headline.
  10. Follow a navigation link and verify the About page.
  11. Check a nested blog URL too. This walkthrough uses a Railway hostname; custom domains also need your own DNS configuration.
