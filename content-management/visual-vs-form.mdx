Primo offers two ways to edit content: edit supported fields directly on the page, or open a structured content form. Inline edits auto-save; form dialog changes require Save.

## Inline editing (on the page)

The page preview shows content in context. Which fields you can edit and which blocks you can rearrange depend on your developer's setup.

**What you see:**
- All blocks stacked vertically
- How content looks in context
- Spacing, layout, and design

**What you can do:**
- Click supported text, rich text, Markdown, images, and links to edit them inline
- Use the form for empty fields, structured values, and Site Field or Page Field references
- Hover over blocks to see the toolbar
- Reorder body sections when the page type allows layout changes
- Click "Edit" to open the form dialog
- Remove body sections when the page type allows layout changes
- Add blocks from the sidebar's available-block list

<Tip>
Use inline editing for quick changes in context. If clicking a value does not open an editing control, use **Edit content** instead.
</Tip>

## Form Editor (Dialog)

Click "Edit" in the block toolbar to open the editor dialog.

**Content Tab:**
- Shows content fields in a structured form, including fields not visible on the page
- Edit text, images, links, etc.
- Scroll through all fields
- See what's filled in and what's empty

**Code Tab** (developers only):
- Edit HTML, CSS, and JavaScript
- See live preview
- Toggle with `Cmd/Ctrl + E`

<Info>
Content editors only see the Content tab. Developers can switch between Content and Code tabs.
</Info>

## When to Use Each

**Edit on the page when:**
- Changing a visible text, image, or link field
- Checking how content looks
- Arranging blocks, if the page type permits it

**Open the content form when:**
- Filling an empty field or editing several fields together
- Editing repeaters, groups, or referenced site and page content
- Reviewing fields that are not visible on the page

## Workflow

Typical editing flow:

1. **Start in visual view** - See the full page
2. **Hover over a block** - Toolbar appears
3. **Click "Edit"** - Form dialog opens
4. **Fill in fields** - Edit content in Content tab
5. **Save** - Changes appear on page
6. **Repeat** - Edit more blocks as needed

<Tip>
You can also press `Cmd/Ctrl + E` while hovering over a block to quickly open the editor dialog.
</Tip>
